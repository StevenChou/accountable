# 本機架構與範例資料

- React 頁面由 FastAPI 的本機 JSON API 取得資料。API 提供公司、聯絡人、商機與活動的讀寫，以及看板、儀表板彙整。後端依 [技術堆疊](../TECH_STACK.md) 使用 SQLAlchemy Core 存取本機 SQLite。欄位、外鍵與階段規則在後端驗證，失敗時前端顯示可採取行動的訊息。
- 開發服務只監聽本機回送介面。瀏覽器透過前端的同來源 `/api` 路徑讀寫。前端停用跨來源讀取，檔案服務限於前端與相依套件目錄。API 只接受本機主機名稱，並拒絕瀏覽器的跨來源請求。SQLite 預設存於 `data/accountable.sqlite3`，也可用 `ACCOUNTABLE_DB_PATH` 指定其他位置，路徑須在前端與相依套件目錄之外。
- 第一次啟動時以虛構的公司、人物和業務情境建立範例資料。內容包含多個產業、三種聯絡人狀態、六個商機階段、近幾個月的成交與失單、未來幾個月預計結案及已逾期的商機，並提供備註、通話、電子郵件及今日、逾期、即將到期和已完成的跟進範例。日期相對於初始化當天產生。正常重啟沿用既有資料，包括使用者清空的列表。
- 備妥工具與相依套件後，`npm run dev` 同時啟動前後端。字型與前端資源由本機提供，瀏覽器開啟與日常操作皆可離線。`npm run seed` 會清除目前選定的本機資料庫內容並恢復範例資料。安裝、啟動與重設步驟記錄在[專案進度](../STATUS.md#在本機執行)。
