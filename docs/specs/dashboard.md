# 儀表板

- 首頁優先顯示待跟進事項與近期活動。未完成且有跟進日期的活動都列入待辦，依本機日期分為逾期、今天到期、未來七天內到期和稍後到期，按此順序排列，各組依到期日由早到晚。完成後即移出待辦，原活動保留於時間軸。
- 近期活動顯示最新 10 筆，包含手動活動與系統產生的階段變更，依發生時間由新到舊排列。待辦和近期活動顯示關聯紀錄、內容摘要與日期，可直接開啟該聯絡人或商機的時間軸。可在待辦清單標記完成。
- 成交摘要顯示本月成交筆數與金額。折線圖呈現最近六個日曆月的每月成交金額，長條圖呈現同期成交筆數，包含本月及零成交月份。階段視覺化依看板欄序呈現六個階段的商機金額，各階段顯示名稱與金額。
- 進行中摘要顯示商機筆數、合計金額與預期營收。階段變更、金額調整或刪除商機後，重新依已儲存資料計算。新增、完成或刪除跟進後，待辦清單同步更新。
