# 資料與關聯

| 紀錄 | 欄位與規則 |
| --- | --- |
| 公司 | 名稱必填，網站、產業、備註可留空。可連結多位聯絡人和多筆商機。 |
| 聯絡人 | 姓名及狀態必填。電子郵件、電話、職稱和所屬公司可留空。狀態為潛在客戶、已確認、既有客戶，新增預設為潛在客戶。 |
| 商機 | 名稱、階段、金額和成交機率必填。公司、主要聯絡人和預計結案日可留空，已結案商機會儲存實際結案日。金額為非負的新臺幣，可輸入至小數兩位，單筆以 JavaScript 可精確表示的最大安全整數分為上限。成交機率為 0 至 100 的整數百分比。 |
| 活動 | 各自隸屬一位聯絡人或一筆商機。包含類型、內容和發生時間，可加上跟進日期與完成狀態。手動類型為備註、通話或電子郵件，發生時間預設為現在。系統會另行產生商機階段變更活動。 |

關聯紀錄使用識別碼連結。日期以本機日曆日判斷與呈現，活動時間轉為本機時間顯示。金額以整數分儲存，避免統計受到浮點精度影響。

## 新增者與最後修改者

- 公司、聯絡人、商機與活動都記錄新增者及最後修改者。新增時兩者皆為執行新增的成員。儲存後續變更時保留原新增者，並將最後修改者更新為執行變更的成員。這項規則也適用於拖放商機、標記跟進完成及刪除時對保留紀錄的關聯更新。後端從已驗證的身分取得操作人。[API 驗證](auth.md#api-驗證)
- 公司、聯絡人與商機的詳情頁，以及聯絡人與商機時間軸上的各筆活動，都以「新增者」標示完整帳號 Email。由成員操作觸發的系統活動以該成員為新增者。初始化的範例紀錄和活動以虛構使用者標示。[範例資料](runtime.md#範例資料)

## 刪除規則

| 刪除對象 | 確認視窗與資料結果 |
| --- | --- |
| 公司 | 顯示會解除連結的聯絡人與商機筆數。保留這些紀錄及其活動，清除其所屬公司連結。 |
| 聯絡人 | 顯示會解除主要聯絡人連結的商機筆數，以及會刪除的活動總數與其中未完成的跟進筆數。保留相關商機與商機自己的活動。 |
| 商機 | 顯示會刪除的活動總數與其中未完成的跟進筆數，包含該商機的階段變更活動。保留公司和主要聯絡人。 |
| 手動活動 | 說明會刪除活動，若有未完成的跟進，也會從儀表板的待辦清單移除。 |

取消確認時資料保持原狀。確認刪除公司、聯絡人或商機時，後端在寫入交易內重算影響筆數。若筆數有變，保留資料並顯示最新筆數，等待使用者再次確認。刪除和關聯處理在同一筆交易內完成。成功後，相關列表、時間軸、看板與儀表板統計反映變更。
