# 商機看板

| 欄序 | 階段 | 預設成交機率 | 品牌色 |
| --- | --- | --- | --- |
| 1 | 新商機 | 10% | Sea Green `#06D6A0` |
| 2 | 已確認 | 25% | Marigold `#FFC145` |
| 3 | 提案 | 50% | Coral `#F78C6B` |
| 4 | 議價 | 75% | Cerulean `#118AB2` |
| 5 | 成交 | 100% | Midnight `#073B4C` |
| 6 | 失單 | 0% | Raspberry `#EF476F` |

- 卡片顯示商機名稱、公司、金額、成交機率、結案日期及逾期標示，連到詳情頁。每欄可新增商機，新表單以該欄階段和預設機率起始。新增時如果直接選擇已結案階段，實際結案日預設為今天。
- 欄內任意位置都可放置卡片，含首位、末位及空欄。拖曳按鈕支援滑鼠和鍵盤操作。同欄拖放只儲存順序。跨欄拖放同時儲存目標位置、階段、預設機率、結案日期變更與一筆系統活動。從表單新增商機或更換階段時，放在目標欄的第一位。儲存成功後，重新整理或重新啟動會顯示相同的順序。
- 看板整體與各欄顯示進行中商機合計金額和預期營收。成交與失單欄顯示階段筆數，該欄的進行中合計與預期營收皆為 `NT$0`。移動成功後更新看板與統計，開啟商機列表即可看到新階段。若移動遭拒，保留原位置並顯示錯誤。回應遺失或結果不明時，重新讀取看板確認已儲存的位置，讀取失敗時提供重試入口。

## 看板移動 API

- 看板移動傳送商機、目標階段及插入點卡片的識別碼。後端將移動的卡片放在插入點卡片之前，省略插入點時放在欄末。後端在一筆交易內更新受影響欄位、順序及活動，儲存成功後前端更新受影響的資料與統計。同一套階段變更規則用於表單與看板。
