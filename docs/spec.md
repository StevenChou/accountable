# Accountable 產品規格

## 要解決的問題

小型企業的客戶資訊與業務進度分散在試算表、電子郵件和同事的記憶裡。業務成員需要查到有哪些往來公司、該找哪位聯絡人、商機進行到哪個階段、上次談了什麼，以及接下來要跟進哪些事項。團隊也需要共用最新資料，並知道紀錄由誰新增。

## 目標與適用範圍

Accountable 是小型業務團隊使用的客戶關係管理系統（CRM）。成員以管理者建立的帳號登入，共用公司、聯絡人、商機與活動，並查看紀錄的新增者。成員可從儀表板查看近期往來與待跟進事項，開啟聯絡人或商機的時間軸並記下下一步，也可從共用頂欄搜尋紀錄及開啟使用者選單。

正式模式連線至 Supabase 取得登入服務與共用資料。本機開發與自動化測試使用 SQLite、範例資料及虛構使用者，可離線執行。

## 選定設計

採用 **A · 跟進工作台**。它把待跟進事項和近期活動放在首頁最上方，方便使用者先找出逾期事項，再回顧最近的客戶往來。 [HTML 設計稿](mockups/1-follow-up.html) · [儀表板截圖](mockups/1-follow-up-dashboard.png) · [商機看板截圖](mockups/1-follow-up-pipeline.png)

- **儀表板**上方左側是待跟進事項，右側是近期活動。下方依序顯示成交與進行中商機摘要、每月成交金額折線圖與成交筆數長條圖，以及各階段商機金額。
- **商機看板**上方橫列顯示進行中商機筆數、合計金額與預期營收。下方是六個階段欄，欄首顯示該階段的統計並提供新增商機入口。較窄的筆電畫面可在看板區內橫向捲動。
