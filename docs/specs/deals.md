# 商機

- 列表顯示名稱、公司、主要聯絡人、階段、金額、成交機率和結案日期，可搜尋名稱、公司或主要聯絡人。詳情頁顯示完整資料、關聯公司及聯絡人的連結，以及商機的活動時間軸。
- 新商機、已確認、提案、議價屬於進行中，顯示預計結案日。成交及失單屬於已結案，顯示實際結案日。進行中的商機若預計結案日早於今天，列表與看板卡片都顯示「逾期」。未填預計結案日或當天到期的商機依原狀態顯示。
- 在商機表單儲存階段變更時套用新階段預設機率。使用者可在新階段存妥後再調整機率。一般編輯與同欄排序保留已存機率，除非使用者直接修改機率。商機階段與聯絡人狀態各自編輯。
- 進行中的商機移到成交或失單時，實際結案日預設為今天，之後可在表單修正為今天或更早的日期。已結案商機在成交與失單之間移動時保留其實際結案日。重新開啟時清除實際結案日，沿用先前的預計結案日（若有），並依新階段套用預設機率。
