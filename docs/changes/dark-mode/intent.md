# 深色模式變更意圖

## 要解決的問題

Accountable 目前只有亮色模式，偏好深色介面的使用者無法切換主題。

## 預期成果

新增深色模式。五個功能區塊的所有頁面及「找不到頁面」都採用目前選擇的主題，並提供相同的切換入口。

## 限制

- 首次開啟時使用亮色模式。同一瀏覽器會保留上次選擇的模式，重新整理頁面或關閉瀏覽器後再開啟皆適用。清除網站資料後回到亮色模式。
- 亮色模式沿用既有外觀，只新增切換控制。
- 色彩集中定義為共用的設計變數（design tokens），供各頁面與元件使用。
- 深色模式的文字與背景須符合[產品規格](../../spec.md#共用介面與行為)的對比要求。
- 圖表、對話框及訊息一律採用目前選擇的模式。
- 新增相依套件前，須先在實作計畫中說明必要性。

## 留待後續處理

- 自動跟隨裝置的主題設定。
- 手機版面。

## 驗收條件

1. `npm run check` 通過。
2. 新增端對端測試，驗證首次開啟預設亮色、可切換模式且重新整理後保留設定，並確認「找不到頁面」沿用目前主題且能切換。
3. 儀表板與商機看板各保存一張亮色及一張深色截圖，共四張，放在 `docs/changes/dark-mode/`。
4. 關閉瀏覽器後，用同一瀏覽器重新開啟 Accountable，確認沿用上次選擇的模式。清除網站資料後重新開啟，確認回到亮色模式。
