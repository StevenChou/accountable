# 共用介面與行為

- 頂端橫向導覽連到五個功能區塊。儀表板在 `/`，公司、聯絡人及商機列表分別在 `/companies`、`/contacts`、`/deals`，各列表路徑加上紀錄識別碼可開啟詳情。商機看板在 `/pipeline`。這些頁面可重新整理，並支援瀏覽器上一頁與下一頁。已刪除的紀錄顯示說明與返回列表的入口。找不到頁面時提供返回儀表板的連結。
- 公司、聯絡人和商機列表都提供搜尋、新增及可按欄名切換升降冪的資料欄。每列可開啟詳情、編輯或刪除。列表預設按名稱或姓名升冪排列，選填欄位的空值在升冪與降冪都排在最後。搜尋忽略前後空白與英文字母大小寫，對各列表指定的欄位比對部分文字。空列表與沒有搜尋結果分別顯示原因。
- 表單標示必要欄位，驗證失敗時顯示欄位提示。編輯公司、聯絡人、商機或手動活動時，表單只送出有變動的欄位，其他欄位沿用資料庫中的值。儲存失敗時保留輸入，刪除失敗時保留原紀錄。讀取失敗時顯示原因與重試入口，統計資料未取得時顯示讀取狀態。已成功儲存的變更會反映在相關頁面。
- 標題及內文用 Instrument Sans，數字用 JetBrains Mono。繁體中文回退至本機系統字型。導覽、欄名、表單、驗證訊息與圖表均用繁體中文，金額加上 `NT$` 並使用千分位。筆電與桌機使用同一套操作，畫面依選定的設計稿製作。

## 亮色與深色模式

- 頂端共用導覽提供主題切換控制。使用者可用滑鼠或鍵盤切換，控制項清楚標示目前模式。五個功能區塊的所有頁面及「找不到頁面」都提供同一切換入口。切換立即套用到目前頁面，跨頁導覽也沿用所選主題。
- 首次開啟 Accountable 時使用亮色模式。主題由使用者在 App 內選擇。重新整理頁面或關閉瀏覽器後用同一瀏覽器重新開啟 Accountable，初始畫面即套用上次的選擇。清除網站資料或無法讀取偏好時，以亮色開啟。瀏覽器禁止儲存時，切換仍在目前頁面生效。
- 亮色模式沿用既有外觀，只新增主題切換控制。亮色使用 `#F0F4F5` 背景、白色圓角面板及 Midnight `#073B4C` 內文。深色使用 `#04232E` 背景、黑色圓角面板及卡片，內文用 Sea Mist `#CDD8DB`。兩種模式的主要操作都用 Sea Green `#06D6A0` 搭配 Midnight 文字。[品牌規範](../../.claude/skills/brand/SKILL.md)
- 導覽、表單、圖表及其標籤與提示、商機卡片、對話框、載入狀態和訊息均使用目前主題的共用色彩變數。商機階段保留品牌色系和階段名稱，深色模式的圖表和看板標記採用在深色背景上清楚可辨的色階。逾期標示使用品牌警示色和「逾期」文字，文字與背景需有足夠對比。
- 深色模式的一般文字與背景對比至少為 4.5:1，大字至少為 3:1，適用於表單、圖表文字、對話框與訊息。主題切換控制的文字在兩種模式都符合相同門檻。深色模式若遇到品牌原色與文字搭配時對比不足，使用符合門檻的同色系色階。[WCAG 2.2 文字對比準則](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)
